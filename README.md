## Carga en GitHub

Si se va a reemplazar el contenido del repositorio existente, mantener la estructura de carpetas exactamente como aparece en este paquete y confirmar los cambios en la rama `main`.

No subir secretos de servidor. El archivo `.env.local` incluido utiliza la clave publishable proporcionada para este proyecto; no contiene `service_role` ni `sb_secret`.
